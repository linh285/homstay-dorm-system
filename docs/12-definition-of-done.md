Một chức năng hoàn thành khi:
- UI gọi được API;
- API có validator, controller, service và repository;
- lưu đúng PostgreSQL;
- kiểm tra role và chi nhánh;
- kiểm tra trạng thái;
- chạy được luồng chính;
- chạy formatting hoặc lint;
- chạy TypeScript typecheck;
- chạy unit test và integration test liên quan;
- chạy build của ứng dụng bị ảnh hưởng;
- không làm hỏng module khác.

Không được ghi “đã pass” nếu lệnh tương ứng chưa thực sự chạy thành công.
